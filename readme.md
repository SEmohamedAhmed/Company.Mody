# Company Management System

A production-style **ASP.NET Core MVC** web application that demonstrates modern .NET development practices, clean architecture, authentication, authorization, and enterprise application design.

## 🚀 Live Demo

**Website:** http://mody.runasp.net/

---

## ✨ Features

* 🔐 Secure authentication and role-based authorization using **ASP.NET Identity**
* 🌐 Social login integration with **Google** and **Facebook**
* 📧 Password reset via **MailKit** email service
* 📱 SMS verification using **Twilio**
* 👥 Complete Employee and Department management with full **CRUD** operations
* 🗄️ Relational database design using **SQL Server** and **Entity Framework Core**
* 🔍 Search functionality for employees and departments
* 🖼️ Image upload and management
* ✅ Client-side and server-side validation with **jQuery Validation**
* 🔄 Asynchronous programming using **async/await**
* 🧩 DTOs and **AutoMapper** for clean data transfer
* 📦 **Repository** and **Unit of Work** patterns for maintainable data access
* 💉 Dependency Injection throughout the application
* 🏗️ Layered Architecture (Presentation, Business Logic, and Data Access Layers)
